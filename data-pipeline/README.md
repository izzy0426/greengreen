# data-pipeline

팀 계산엔진 결과 CSV → 화면용 JSON (`public/data/`). 엔진 결과가 바뀌면 이 스크립트만 다시 돌린다.

## 원본 (저장소에 올리지 않음 → `data-pipeline/raw/`에 둔다)

Drive `계산엔진/엔진결과_20261118/`
- `계산엔진_결과표_20261118.csv` — 758단위 × 5년 × 가격 4 = 15,160행
- `요약_업종연도시나리오_20261118.csv`, `연도별_요약_현재유지가격_20261118.csv`, `합계범위_20261118.csv`, `가정_20261118.csv`
- `참고/지표_참고_20261118.csv`, `참고/민감도_결과표_20261118.csv`

## 출력 (명세서 4장)

| 파일 | 내용 |
| --- | --- |
| `units.json` | 758단위 목록 |
| `unit/{id}.json` | 가격 4 × 연도 5 |
| `article.json` | 아티클 차트별 집계 |
| `lab-*.json` | 실험실 레버 조합별 결과 |

시나리오 이름 매핑: 3차 회귀 → low(낮은 가격) · 현재 유지 → now(지금 가격) · IEA 현행정책 → high(높은 가격) · 전환 필요 → max(매우 높은 가격)
