# data-pipeline

팀 계산엔진 결과 CSV → 화면용 JSON (`public/data/`). 엔진 결과가 바뀌면 이 스크립트만 다시 돌린다. 화면 코드는 그대로.

## 실행

```bash
pip install pandas numpy
python data-pipeline/build_json.py    # raw/ → public/data/
python data-pipeline/check_json.py    # 하이파이 숫자와 비교 (FAIL 0이어야 함)
```

## 출력 (명세서 4장)

| 파일 | 내용 | 크기 |
| --- | --- | --- |
| `units.json` | 758단위 목록. 열 이름 1번 + 행 배열(용량 때문), 화면에서 `unpackUnits()`로 펼침 | 185KB (목표 200KB) |
| `unit/{key}.json` | 가격 4 × 연도 5. `key` = 분석단위ID의 sha1 앞 10자 (ID에 한글·괄호·& 있음) | 약 8KB |
| `article.json` | 아티클 집계: 연도별 합계, 업종 비중, 등급, 적자 전환, 상위 10곳, 실효가격, 2015~2025 실적, 합계 범위 | 25KB |

## 변환 규칙

- 가격 시나리오: 3차 회귀 → `low`(낮은 가격) · 현재 유지 → `now`(지금 가격) · IEA 현행정책 → `high`(높은 가격) · 전환 필요 → `max`(매우 높은 가격)
- 등급: ① `loss` · ② `high` · ③ `mid` · ④ `low` · ⑤ `none` · 재무 없음 `nofin`
- 단위: 배출·할당·구매량 t, 금액 원 (정수 반올림). 비율은 유효숫자 4자리
- `displayName`: 이름에서 `주식회사`·`(주)`·`㈜`만 뺌. 별칭(옛 상호, 영문 약칭)은 만들지 않음 (명세서 10장)
- 2015~2025 실적: EDA 패널에서 `분석제외`를 뺀 표본 합계
