# 결정 기록 — 기준이 없던 항목

명세서·하이파이·팀 자료에 기준이 없어 개발 중 임시로 정한 것들. 팀이 다르게 정하면 여기 적힌 위치만 바꾸면 된다.
데이터 숫자는 모두 Drive `계산엔진/엔진결과_20261118/`와 `계산엔진_김서진.py` 기준.
