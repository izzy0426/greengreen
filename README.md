# 배출권 길라잡이

4차 배출권거래제(2026~2030)에서 어느 기업이 배출권을 얼마나 사야 하고, 그 비용이 이익에 비해 얼마나 큰 부담인지 보여 주는 웹 서비스입니다. 데이터 분석 학회 학술제 프로젝트의 데모 버전입니다.

- **아티클** — 4차 배출권의 청구서가 누구에게 가는지 숫자와 차트로 읽는 이야기
- **기업** — 기업명·초성으로 검색해 배출·할당·이월, 3차 할당 대비 배출, 재무, 4차 구매 필요 여부와 가격별 탄소비용 보기
- **실험실** — 장관이 되어 배출권 가격·할당 규칙 레버를 바꾸고 2030년 결과 확인하기

모든 숫자는 팀 계산엔진 결과(2026.11.18)에서 옵니다. 개발 안내와 결정 기록은 팀 Drive `07_MVP` 폴더에 있습니다.
